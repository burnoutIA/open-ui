# Visual Directions

Utiliser ces directions comme points de depart. Les adapter au produit au lieu de les appliquer telles quelles.

## Control Room Calme

- Pour : outils B2B, operations, monitoring, gestion.
- Layout : dense, grilles stables, zones de statut, actions proches des donnees.
- Signature : hierarchie froide mais humaine, accent couleur rare, scan rapide.
- Risque : devenir un dashboard standard sans decision claire.

## Editorial Product

- Pour : produits avec contenu, expertise, service premium, onboarding.
- Layout : grands titres utiles, sections rythmees, blocs narratifs, medias choisis.
- Signature : typographie assumee, blancs controles, textes qui guident vraiment.
- Risque : trop marketing si l'utilisateur vient accomplir une tache.

## Canvas Spatial

- Pour : outils de creation, mapping, planification, IA, workflows non lineaires.
- Layout : espace principal libre, panneaux contextuels, selection directe.
- Signature : objets manipulables, zoom, relations visibles.
- Risque : perdre les utilisateurs si les affordances sont faibles.

## Command Palette First

- Pour : power users, outils techniques, IA copilote, apps frequentes.
- Layout : recherche/action centrale, resultats structures, raccourcis.
- Signature : vitesse, clavier, historique, suggestions.
- Risque : masquer les options pour les nouveaux utilisateurs.

## Timeline / Journey

- Pour : parcours patient, dossier, projet, pipeline, historique.
- Layout : progression chronologique, etats, decisions passees/futures.
- Signature : comprendre ou on en est sans lire tout l'ecran.
- Risque : rigide si les objets ne sont pas naturellement temporels.

## Object-Centric Detail

- Pour : CRM, sante, gestion de cas, tickets, inventaire.
- Layout : un objet principal vivant, contexte lateral, actions contextualisees.
- Signature : l'objet devient la scene, pas une ligne dans un tableau.
- Risque : moins efficace pour comparaison massive.

## Tactile Human

- Pour : wellness, education, produit grand public, marque differenciante.
- Layout : surfaces douces, medias reels, texture subtile, asymetrie controlee.
- Signature : moins "IA lisse", plus humain et memorable.
- Risque : decoratif si la tactilite ne sert pas la comprehension.

## Brut Functional

- Pour : outils experts, devtools, finance, legal, infra.
- Layout : typographie nette, peu d'ornement, separations franches, monospace ponctuel.
- Signature : confiance par precision, pas par decoration.
- Risque : paraitre inacheve si le rythme et les details sont faibles.
