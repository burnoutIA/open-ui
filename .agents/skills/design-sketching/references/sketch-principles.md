# Sketch Principles

## Framework de depart

Utiliser la logique surface + contexte + contraintes :

- Build quoi : surface, contenus, actions, etats.
- Used by qui : utilisateur, expertise, frequence, contexte emotionnel.
- In quel moment : declencheur, urgence, environnement.
- To achieve quoi : decision, action, comprehension.
- With quel gout : contraintes visuelles, interdits, references, niveau d'audace.

## Ce qui marche bien pour l'IA UI

- Donner un contexte d'usage concret produit de meilleures compositions que demander un style.
- Donner des contraintes de gout produit plus de caractere que demander "premium" ou "moderne".
- Demander plusieurs directions avec hypotheses differentes evite la moyenne generique.
- Une bonne direction a une idee centrale memorable : pas seulement des composants bien alignes.
- Les critiques riches ameliorent mieux les sorties que des notes ou preferences vagues.

## Regles de sketch

- Un sketch doit clarifier une hypothese, pas prouver que tout est fini.
- Les donnees factices doivent soutenir la decision utilisateur.
- Les etats importants doivent etre visibles des le sketch : vide, loading, erreur, actif, succes, attention.
- Le responsive doit etre pense tot si la composition est structurante.
- L'accessibilite reste une contrainte creative : contraste, focus, tailles tactiles, libelles et ordre logique.
- Les micro-interactions doivent expliquer, confirmer, guider ou reduire l'effort.

## Tendance durable, pas effet de mode

Utiliser les tendances comme materiau :

- UI plus contextuelles : interface qui change selon l'intention, pas decoration dynamique.
- Interfaces d'IA plus lisibles : provenance, confiance, etats d'attente, controle utilisateur.
- Tactilite et chaleur : textures fines, imperfections controlees, medias reels, signes de fabrication.
- Densite calme : plus d'information sans bruit, alignements nets, rythmes clairs.
- Motion utile : transition qui preserve le contexte ou explique une relation.

Eviter de copier une tendance si elle ne renforce pas l'usage.
