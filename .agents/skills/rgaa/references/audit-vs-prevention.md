# Audit Vs Prevention

Le skill RGAA sert surtout a prevenir et corriger pendant la conception. Un audit RGAA complet demande une methode plus stricte.

## Prevention / Revue Agentique

Approprie pour :

- creer un composant accessible par defaut ;
- corriger une page ou un template ;
- relire un composant avant integration ;
- documenter les obligations d'usage ;
- detecter les risques evidents avant audit.

Formulation recommandee : "revue RGAA", "prevention RGAA", "risques RGAA", "points a verifier".

## Audit Complet

Necessite :

- un echantillon de pages representatif ;
- l'environnement de test RGAA ;
- des tests manuels avec technologies d'assistance quand requis ;
- une decision conforme / non conforme / non applicable pour chaque critere ;
- des contenus et parcours reels ;
- une declaration ou un rapport selon le contexte legal.

Formulation a eviter sans ce cadre : "site conforme RGAA", "audit complet termine", "certifie".

## Format De Decision

- `Conforme` : preuve suffisante dans le cadre teste.
- `Non conforme` : probleme observe avec impact.
- `Non applicable` : critere absent du perimetre.
- `A verifier manuellement` : besoin d'un navigateur, lecteur d'ecran, contenu reel ou jugement humain.
