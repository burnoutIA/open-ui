---
Relis une modification existante avec l'angle RGAA.

1. Inspecte le diff et la cible utilisateur.
2. Identifie les themes RGAA concernes.
3. Verifie si le changement degrade ou ameliore semantique, clavier, focus, labels, erreurs, alternatives, navigation ou consultation.
4. Priorise les regressions observables et les manques de tests.
5. Reponds d'abord avec les risques/problemes, puis les corrections proposees et validations manquantes.
