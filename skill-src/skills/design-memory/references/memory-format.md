# Memory Format

Utiliser des entrees courtes, fusionnees, datees.

## Exemple MEMORY.md

```md
### YYYY-MM-DD - Titre court

**Type**<br>
preference | project_rule | agent_rule_candidate | rejected_direction | accepted_direction | open_question

**Contexte**<br>
Situation concrete ou retour utilisateur.

**A retenir**<br>
- Regle ou apprentissage reusable.
- Limite ou nuance importante.

**Suite utile**<br>
- Corriger un livrable.
- Ajouter a la direction stabilisee de `MEMORY.md`.
- Promouvoir vers un skill plus tard.
```

## Regles de hygiene

- Une entree doit aider une future decision.
- Supprimer ou fusionner les doublons.
- Ne pas garder les etapes de travail ordinaires.
- Ne pas transformer MEMORY.md en changelog.
- Quand une regle devient stable, la deplacer vers la direction stabilisee de `MEMORY.md` ou un skill.
